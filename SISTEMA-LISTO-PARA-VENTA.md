### **Paso 2: Instalar Licencia en Modo Desarrollo**
```bash
cd C:\workspaceDRT\DRTPos
npm run dev  # Inicia aplicación en modo desarrollo
```

**En la aplicación:**
1. Ir a sección **"Licencias"** (último botón del menú izquierdo)
2. Copiar el código de licencia de arriba
3. Pegarlo en el campo "Código de Licencia" 
4. Hacer clic en **"Instalar Licencia"**
5. Verificar que aparezca ✅ **"Válida"** con 30 días restantes

## 💰 **PROCESO COMERCIAL REAL**

### **Para el Proveedor (Tú):**
1. **Enviar artefacto** comprimido al cliente
2. **Cliente reporta** error de licencia y proporciona Hardware ID  
3. **Generar licencia** específica: `node generate-license.js`
4. **Enviar código** al cliente por WhatsApp/Email
5. **Cliente instala** licencia y usa el software

### **Para el Cliente:**
1. **Descomprimir** archivo recibido
2. **Ejecutar** aplicación → Error de licencia
3. **Contactar proveedor** con Hardware ID
4. **Recibir código** de licencia
5. **Instalar licencia** desde la interfaz
6. **Usar software** normalmente

## 🔒 **CARACTERÍSTICAS DE SEGURIDAD**

### **Protección Implementada:**
- ✅ **Hardware Fingerprinting** - Licencia atada al equipo específico
- ✅ **Encriptación AES-256** - Códigos imposibles de falsificar  
- ✅ **Validación de Expiración** - Control automático de vencimiento
- ✅ **Bloqueo Total** - Sin licencia = aplicación no funciona
- ✅ **Bypass de Desarrollo** - Desarrollo sin restricciones

### **Imposible de Piratear:**
- ❌ No se puede copiar a otro equipo sin nueva licencia
- ❌ No se puede modificar fecha del sistema para extender
- ❌ No se puede usar el mismo código en múltiples equipos
- ❌ No se puede ejecutar sin validación de hardware
